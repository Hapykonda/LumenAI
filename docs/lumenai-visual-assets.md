## Reglas de uso

- Usar `next/image` para assets grandes en rutas publicas.
- Usar SVG solo para iconos, estados vacios vectoriales o diagramas simples.
- Usar WebP o AVIF para renders de producto y fondos.
- Mantener alt text descriptivo.
- Evitar imagenes decorativas que prometan actividad inexistente.
- No mostrar metricas, mapas, clientes o ubicaciones inventadas como si fueran reales.
- Versionar nombres cuando se reemplacen assets: `-v2`, fecha corta o contexto del modulo.
